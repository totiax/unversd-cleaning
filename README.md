Sitio de una sola página para un negocio local de limpieza, pensado para convertir visitas en pedidos de presupuesto. Dirección visual cálida y confiable, con el contenido real del negocio.

## Lo destacado

- **Slider antes / después** para mostrar resultados reales.
- **Formulario de presupuesto** y contacto directo por llamada o SMS.
- **Animaciones de entrada y scroll** con Framer Motion.
- **Tokens de marca** propios en Tailwind y tipografías Fraunces, Manrope y Caveat.

## Correrlo en local

```bash
npm install
npm run dev
```

Abrí [localhost:3000](http://localhost:3000).

## Estructura

```
app/          # App Router (layout y página)
components/   # Hero, BeforeAfter, Gallery, Contact, etc.
public/       # imágenes
```
